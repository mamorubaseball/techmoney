# YouTube動画から自動でブログ化する構想

## 1. 目的と背景
- **目的**: 投資リサーチ用として作成したYouTube動画の台本（Markdown形式）を、独自の静的HTMLブログとして自動で公開できる基盤を構築する。
- **課題と解決策**:
  - **WordPressの不採用**: WordPressにHTMLをそのまま貼り付けるとCSSの汚染や型崩れが発生するため、完全自作の静的HTMLブログ（GitHub Pages等を想定）として構築する。
  - **構造化の課題**: 静的サイトの弱点である「各記事への導線（インデックス）」の更新を手作業で行うのは非効率なため、Pythonスクリプトを用いて `index.html` を動的に自動生成する仕組みを作る。

## 2. 全体ワークフロー

1. **台本の作成（既存プロセス）**:
   - `/Users/mamoru/techmoney/{月}/{銘柄名}/` ディレクトリ内に `{銘柄名}.md` として台本を作成。
2. **HTML記事の生成**:
   - `design.md`（統一デザインガイド）に準拠した形式で、台本からHTMLファイル（`blog_{銘柄名}.html`）を生成する。
   - 生成時、HTMLの `<head>` 内に `<meta>` タグ（カテゴリ、日付、ティッカーなど）を埋め込む。
3. **インデックス（一覧ページ）の自動生成**:
   - ブログ構築用スクリプト（例: `build_blog.py`）を実行。
   - スクリプトが全ての `blog_*.html` を走査し、`<meta>` タグから情報を抽出。
   - カテゴリ別・日付順に整理された `index.html` を出力する。
4. **デプロイ**:
   - 生成されたHTML群をGitHub PagesなどにPushして公開。

## 3. ディレクトリ構成イメージ

```text
/Users/mamoru/techmoney/
├── .agent/
│   ├── skills/              # 自動化スクリプトなど (generate_video_gaiyou.py 等)
│   └── workflow/            # ワークフロー手順書
│       ├── design.md        # ブログ用HTMLのデザインガイド（CSS変数、クラス名など）
│       └── md_to_blog_html.md # MD→HTML変換フロー定義
├── youtube-to-blog/         # ブログ自動生成システムの開発・管理ディレクトリ
│   ├── build_blog.py        # index.htmlを自動生成するメインスクリプト（今後作成）
│   └── templates/           # index.html用のデザインテンプレート（今後作成）
├── {月}/
│   └── {銘柄名}/
│       ├── {銘柄名}.md       # 元の動画台本
│       └── blog_{銘柄名}.html # 生成されたブログ記事
└── index.html               # 自動生成されるブログのトップページ
```
